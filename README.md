# OrbWar — 球球领土战争

单文件 Canvas 策略对战。左板弹珠穿过 X8/X4/X2 缝隙链式翻倍，落到武器槽向对应势力输送弹药；右板四方势力各自旋转炮台，互相争夺约 200 万像素的领土。

![preview](preview.jpg)

## 运行

- 网页版：双击 `index.html`，任意现代浏览器打开即可，零依赖。
- 网页托管：推送到 GitHub 后开启 Pages，根目录即游戏入口。
- 桌面版（Windows）：见下方「桌面版」一节，下载离线 exe，双击即玩。

## 桌面版（Windows）

`OrbWar.Exe` 是 .NET 9 + WebView2 外壳，把游戏内嵌为单机 exe，离线运行、不依赖浏览器。两种分发形态（见 [v1.0.3 Release](https://github.com/xiaowlx/OrbWar/releases/tag/1.0.3)）：

| 版本 | 文件 | 说明 |
| --- | --- | --- |
| 自包含 | `OrbWar-1.0.3-win-x64-self-contained.zip` | 打包 .NET 运行时，本机无需安装任何环境 |
| 依赖运行时 | `OrbWar-1.0.3-win-x64-framework.zip` | 体积小，需本机已装 .NET 9 运行时（WebView2 由 Win11 预装） |

解压后运行 `OrbWar.exe` 即可。源码见仓库 `OrbWar.Exe/`（`OrbWar.Exe.csproj` / `Program.cs` / `build_exe.bat` / `build_exe_fd.bat`），`build_exe.bat` 一键重新构建自包含版。

## 玩法（全程自动，无需操作）

- 左板弹珠从顶部下落，碰到栏杆随机弹跳。
- 倍数层 `X8 / X4 / X2 / — / — / X2 / X4 / X8`：穿过非空缝隙 → 当前数值翻倍并**回顶重落**，可连吃链式翻倍。
- 武器层（9 槽对称布局 `机枪 风暴 狙击 盾 大球 盾 狙击 风暴 机枪`，中间「大球」槽高亮）：资源球落到哪一列，对应势力炮台就按当前数值开火一次，弹珠数值归 1k 回顶。
- 右板势力各自旋转炮台，按蓄能队列连续开火；领地面积严格等于子弹消耗的数值之和（**无自动扩张**）。
- 蓄能空时炮台自动发射 1px 细弹维持推进。

## 五种武器

| 武器 | 特点 |
| --- | --- |
| 狙击 (sniper) | 高速、最细弹道（密度最大），精准开路 |
| 机枪 (mg) | 短时间连射多发（按数值 / 1000 颗，单发上限 120 颗） |
| 大球 (big) | 巨大球形弹丸，撞击积累动量并偏转 |
| 护盾 (shield) | 势力周围出现吸收数值的环形护盾，抵挡来袭子弹 |
| 风暴 (storm) | 机枪强化版：更高射速 + 炮台旋转速度 ×3 |

## 调参（可选）

`index.html` 顶部集中了主要常量（`TARGET`、`MG_UNIT`、`BIG_MOMENTUM`、`IDLE_RATE`、`DENS` 等），改值后刷新即可。

## 技术要点

- 单文件 HTML，零网络请求、零外部资源、零构建步骤。
- 战场约 200 万像素（1677×1193）离屏 Uint32 缓冲，每帧增量写入变化像素，60fps 友好。
- 五种武器差异化：狙击为独立锥形弹（前尖后宽，占坑与可见锥形一致），大球为最大球形弹，其余按数值在 2–20px 间变化，并随数值消耗实时变细。
- 资源球防卡死：最小穿透碰撞修正 + 同向最小横向速度 + 窗口式卡死保险三重叠加，长跑不冻结。
- 已通过 headless 回归（node vm 跑 500s）：0 崩溃、0 出界、领地面积恒等于占用格数。

## 更新日志

### v1.0.3（相较 v1.0.2）
- **武器槽重做**：5 槽 → 9 槽对称布局（机枪 风暴 狙击 盾 大球 盾 狙击 风暴 机枪），中间大球槽高亮。

- **护盾吸收修复**：子弹在盾环边缘即被优先吸收，溢出才扣 HP，修正此前「穿盾」与浮字逻辑。

- **开局 / 录像整合**：移除开始遮罩，「开始」与「暂停」合一；录像改为「录像本局」（开战前点亮，结束自动保存）。
- **调参**：母球内缩 64→150、怠速弹 300→420、阻拦杆剔除贴边列。
- **显示 / 渲染**：新增「M」兆单位格式；薄叠原图使细痕迹覆盖旧色、边缘更平滑。
